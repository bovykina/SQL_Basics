# Реляционная модель данных и SQL

## Описание
В учебном проекте изучила основы SQL на примере реляционной базы данных пиццерий, клиентов, меню, посещений и заказов. Написала запросы для фильтрации и сортировки данных, работы с диапазонами дат, вычисляемыми полями и вложенными подзапросами в SELECT и FROM. Отдельное внимание уделила условиям заданий и ограничениям на использование SQL-конструкций.

## Полученные навыки
- Выборка и фильтрация данных - использовала SELECT, WHERE, логические условия и операторы сравнения
- Сортировка и уникальность результатов - применяла ORDER BY с разными направлениями сортировки и DISTINCT для исключения дубликатов
- Работа с диапазонами - фильтровала данные по диапазонам дат и числовым значениям с помощью BETWEEN и операторов сравнения
- Вычисляемые поля и условия - формировала строки из нескольких полей и использовала CASE для проверки условий
- Вложенные запросы - применяла подзапросы в SELECT и FROM для получения и обработки данных без использования JOIN там, где это запрещено

## Этапы проекта
1. Изучение модели данных, разбор назначения таблиц, полей, первичных и внешних ключей
2. Базовые запросы, выполнение выборки данных по городу, полу и рейтингу, а также сортировки результатов
3. Фильтрация и преобразование данных, использование диапазонов дат, исключение дубликатов, вычисляемых полей и проверка условий
4. Работа с подзапросами, составление запросов с внутренними выборками в частях SELECT и FROM
5. Проверка требований, учитывая ограничения заданий, проверка условий выборки и порядок сортировки

## Заключение
Проект помог закрепить основы SQL и научиться извлекать нужную информацию из реляционной базы данных с помощью различных условий, сортировки, вычисляемых полей и вложенных запросов. Эти навыки применимы в работе системного и бизнес-аналитика при анализе данных, проверке требований и подготовке выборок для отчетов.
